🛒 SimpleStoreSQL

A SQL-based Store Management and Data Analysis Project designed to practice database creation, data manipulation, and analytical SQL queries.

📌 Project Overview

SimpleStoreSQL is a SQL project that demonstrates how SQL can be used to manage and analyze data for a simple store.

The project includes SQL queries for working with store-related data and extracting meaningful insights from the database.

🛠️ Technologies Used
SQL
MySQL
🗄️ SQL Concepts

This project focuses on practical SQL concepts such as:

Database and table creation
Data insertion
SELECT queries
WHERE filtering
ORDER BY sorting
Aggregate functions
GROUP BY
HAVING
JOIN operations
Subqueries
Data analysis using SQL

Only keep the concepts above that you actually used in SimpleStore.sql.
